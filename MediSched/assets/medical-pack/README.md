# MediSched asset pack

46 reusable visual assets: 8 PNG illustrations and 38 SVG files.

These assets recreate the look of the five MediSched mockups; they are not exact extractions from the flattened images. The illustrations were generated with the built-in image generation tool. The brand, icons and backgrounds were drawn as scalable SVG assets. No project source was changed.

## Where to use them

- Landing hero: illustrations/hero-medical-calendar.png
- Dashboard next visit: illustrations/dashboard-calendar-stethoscope.png
- Booking and authentication: illustrations/booking-auth-medical-still-life.png
- Mobile next visit: illustrations/mobile-calendar.png
- Email verification: illustrations/email-verification-envelope.png
- Independent decorative elements: illustrations/red-stethoscope.png, medical-plus-cube.png, blush-plant.png
- Logo: brand/medisched-mark.svg and medisched-wordmark.svg
- Landing feature art: features/create-account.svg, choose-visit.svg and appointment-history.svg
- Decorative backgrounds: backgrounds/blush-halo.svg and blush-ellipse.svg
- Interface icons: icons/ (31 files)

## Palette and typography

Crimson #CC2343; white #FFFFFF; cloud gray #F6F7F9; blush #FFF1F3; charcoal #202632; muted slate #6C7280.
Typography reference: Inter with system sans-serif fallback. No font binaries are included. The editable SVG wordmark uses live text and its appearance depends on available fonts.

## Asset notes

PNGs retain transparent alpha and soft shadows. They are raster illustrations, not animated 3D models. The hero calendar's date 14 is decorative.
Icons use currentColor when inlined; standalone SVG images default to black.
Cards, buttons, form fields, navigation, appointment text and profile initials are live interface elements, not artwork assets. Keep those editable and populated from actual application data during implementation.
No HTML, CSS, React, dependencies or implementation are included.

PROMPTS.md contains the shared art direction and each individual generation prompt. manifest.json lists every asset.
